# Kieu Ngan's Portfolio - Hybrid UI/UX Designer

Đây là kho mã nguồn Portfolio cá nhân của mình. Giao diện được thiết kế theo phong cách tối giản (Minimalist & Elegant), kết hợp giữa tư duy hệ thống của một sinh viên IT và góc nhìn thẩm mỹ của một UI/UX Designer.

## Công nghệ sử dụng

Để web chạy nhanh, nhẹ và dễ dàng đẩy lên GitHub Pages, mình ưu tiên những công cụ đơn giản:
- HTML5: Dựng bộ khung cấu trúc cơ bản.
- Tailwind CSS (qua CDN): Giúp thiết kế giao diện tự động thích ứng với mọi kích thước màn hình mà không cần cài đặt phức tạp.
- v0 by Vercel: Công cụ AI giúp mình tạo nhanh các bản demo để minh họa cho dự án.

## Cách chạy dự án trên máy tính

1. Tải code về máy (bằng cách tải file .zip) hoặc dùng lệnh sau trong Terminal:
   git clone https://github.com/ngan-bui/my-portfolio.git

2. Mở thư mục vừa tải về và nhấp đúp vào file `index.html` để xem trực tiếp trên trình duyệt web. 

(Nếu bạn dùng VS Code, khuyên dùng tiện ích Live Server để trang tự động làm mới mỗi khi bạn sửa code nhé).
